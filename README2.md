# Uvod u Pandoc

Pandoc je univerzalni konverter dokumenata

## Naredbe

Provjera instalacije Pandoca u terminalu.
```
pandoc --version
```
Gdje se nalazi instalacija Pandoca na nasem racunalu, odaberite nize navedenu naredbu.
```
which pandoc
```

Prica se nastavlja. Predaja zadatka funkcionira preko [Merlina](https://merlin.srce.hr).
