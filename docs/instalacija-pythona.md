# Instalacija pythona - vodic

- [Preuzmite najnoviju verziju pythona s ovog linka.](https://www.python.org/ftp/python/pymanager/python-manager-26.4.msix)
- Instalirajte python pomocu carobnjaka
- Za provjeru uspjesnosti, u terminal unesite komandu:  
```
python --version
```  
Ukoliko dobijete odgovor nalik "Python 3.15.0", python je uspjesno instaliran.

- unutar datoteke instalacije, pronadjite i pokrenite python.exe
- u svojstveni terminal, unesite naredbu:
```
print ("Hello world!")
```
Od terminala biste trebali dobiti povratni odgovor "Hello World!"
